Reading this tracker: Chaptered bills are law; a vetoed bill’s proposed requirements did not become law. County impact colors run from red for a Development Code update to green when no Planning change is identified. Purple means the impact needs review. Bill numbers can be reused in later sessions, so the session is stored with every bill.
